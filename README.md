# GCP MCP

Works with Google Cloud. This plugin installs and configures it in your workspaces.

Upstream server docs: https://www.npmjs.com/package/gcp-mcp

Installs from the Camillia hub as `gcp-mcp-ec8565`. On every new task the plugin posts
the ready-to-paste `mcp.servers` entry and the setup steps as a task comment.
